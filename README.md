# 📝 NoteGenius - The Smart Note-Taking App

## 🚀 Overview  
NoteGenius is an innovative web-based note-taking application designed to enhance productivity and organization. With features like text and voice input, tag-based sorting, folder organization, and version-controlled notes, NoteGenius helps users efficiently manage their notes.  

## 🔑 Key Features  
✅ **Effortless Note Management** - Create, read, update, and delete (CRUD) notes seamlessly.  
✅ **Voice Note-Taking** - Record voice notes and transcribe them into text.  
✅ **Tag-Based Sorting** - Organize and filter notes easily with custom tags.  
✅ **Folder Organization** - Keep your workspace clean by grouping notes into folders.  
✅ **Version Control** - Every edit creates a new version, allowing you to undo, redo, and restore previous versions.  

## 🔮 Future Enhancements  
☁️ **Cloud Integration** - Access your notes from any device.  
🎙 **Improved Voice Recognition** - Enhanced transcription accuracy.  
🔐 **Enhanced Security** - Data encryption for privacy protection.  
🎨 **Customization Options** - More folder and tag customization for better organization.

## 🔧 Installation  
Follow these steps to set up NoteGenius on your local machine:  

1. **Clone the repository**  
   ```sh
   git clone https://github.com/OsandaLakshitha/NoteGenius.git
   cd NoteGenius
   ```  
2. **Install dependencies**  
   ```sh
   npm install  # If using Node.js
   ```  
3. **Run the application**  
   ```sh
   npm start  # Start the development server
   ```

## 💡 How to Use  
- **Create Notes** - Type or record voice notes.  
- **Organize Notes** - Use tags and folders for easy retrieval.  
- **Edit & Delete** - Modify or remove notes as needed.  
- **Restore Versions** - Recover previous versions if needed.
